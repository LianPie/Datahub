# DataHub Cloud Storage

A simple cloud storage web application built with pure PHP.

## About
University group project. Upload, download, and manage files in the cloud.
Built without frameworks.

## Features
- Upload files
- Download files
- Delete files
- CreateFolders
- List all uploaded files
- File size and type display
- -Manage Space Used By user

## Technologies
- PHP (vanilla, no framework)
- HTML, CSS
- MySQL

## How to Run
1. Clone the repo
2. Import `database.sql` to MySQL
3. Update database connection in `config.php`
4. Place project in `htdocs` (XAMPP) or `www` (WAMP)
5. Open `http://localhost/Datahub`
