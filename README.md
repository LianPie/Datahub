# DataHub Cloud Storage

A simple cloud storage web application built with vanilla PHP and MySQL.

## Overview

DataHub is a file management web application developed as a university group project.

The application allows users to upload, download, and manage files through a web-based interface. The project was built without using any PHP frameworks, providing experience with core PHP concepts, database interaction, and building a complete web application from scratch.

## Features
- Upload files
- Download files
- Delete files
- CreateFolders
- List all uploaded files
- File size and type display
- -Manage Space Used By user

## Technologies
- PHP (vanilla, no framework)
- HTML, CSS
- MySQL
- JavaScript

## How to Run
1. Clone the repo
2. Import `database.sql` to MySQL
3. Update database connection in `config.php`
4. Place project in `htdocs` (XAMPP) or `www` (WAMP)
5. Open `http://localhost/Datahub`
